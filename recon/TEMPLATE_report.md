# Разведка ЭБУ: `<ecu-id>`

Заполняется разведывательной сессией. Только факты из лога и с экрана. Разделы без данных — писать «не выполнялось» и почему.

| Поле | Значение |
| --- | --- |
| Дата | ГГГГ-ММ-ДД |
| Папка | `recon/logs/<дата>_<ecu-id>/` |
| Оператор | |
| Разведывательная сессия | идентификатор/ссылка сессии Claude |
| Прошивка пульта (из баннера) | `VCM READY. FW …` |
| Пресет пульта при подключении | `… SA:… FIX/AUTO`, маркер на экране |

| Поле | Значение |
| --- | --- |
| Двигатель (модель, номер) | |

| Машина / стенд | |

## 2. Файлы

- `serial.log` — сырой лог, с какой по какую минуту.
- `summary.md` / `summary.json` — автосводка.
- Другие файлы (фото, сканы).

## 3. Факты

### 3.1. Шина
Ожила ли шина после зажигания (`BUS alive`), `rxps=` в heartbeat, число `BUS lost`/`BUS alive`. Инвентарь PGN (`PGN seen …`): список.

### 3.2. Идентификация ЭБУ

| Запрос | Ответ (данные / NACK / нет ответа) | Длина, байт | Текст / hex (первые 60 символов, полностью в summary) |
| --- | --- | --- | --- |
| Component ID 65259 (`q FEEB`) | | | |
| Software ID 65242 (`q FEDA`) | | | |
| Address Claim 60928 (`q EE00`) | | | |
| ECU ID 64965 (`q FDC5`) | | | |
| VIN 65260 (`q FEEC`) | | | |

Отпечатки `ID done … fp=0x…`: A2 = …, A3 = …, A4 (после питания) = …; совпали: да/нет. `name='…'`. Сколько циклов опроса потребовалось (`ID request … attempt N`).

### 3.3. Пресет и привязка
Пресет и маркер до привязки, команда/действие привязки (шаг A6: `p N` или длинный READ), строка `PRESET -> …`, результат проверки A7 (`ECU opoznan`, маркер `A`): да/нет.

### 3.4. Двигатель и управление

| Параметр | Значение |
| --- | --- |
| Холостой после пуска (`act=`), `T=` в начале и в конце | |
| `ctrl=` на холостом | |
| B4 холодный: `set=`, `act=`, `ctrl=` при педали | |
| B5 прогретый: `set=`, `act=`, `ctrl=`, `*` на экране, задержка отклика | |
| B6 полная педаль: `act=` | |
| Рывки, провалы, странности | |

### 3.5. Автоподбор адреса (если пресет AUTO)
`SWEEP start` при холостом …; последовательность `SWEEP next SA=…`; результат `SA FOUND 0x… (SPN1483|rpm)` или `SWEEP aborted`; нажат ли CLEAR, `SA saved`.

### 3.6. Коды неисправностей
Число активных по `>>> DTC:`, список `SPN FMI OC CM`; DM1 как одиночный кадр или BAM; пришёл ли DM2 на экран ошибок (`DM2 1-frame` / `BAM start pgn=65227`): да/нет. Сброс не выполнялся.

### 3.7. Живые данные
Страницы 1–4: значения или `---` по каждому параметру.

### 3.8. Аномалии
`TSC1 TX FAIL` (сколько), `CAN re-init` (сколько, когда), повторные баннеры `=== START VCM` (перезагрузки, когда), минимум `ram=`, `EEPROM: defaults`, `BAM seq gap`.

## 4. Отклонения от процедуры
Что из A1–B9 не выполнено или выполнено иначе и почему. Команды `a`/`m`, если применялись по просьбе оператора.
