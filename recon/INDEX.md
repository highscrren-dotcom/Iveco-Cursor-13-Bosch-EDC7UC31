# Индекс разведки ЭБУ

Одна строка на папку `recon/logs/<дата>_<ecu-id>/`. Заполняет разведывательная сессия после каждого ЭБУ. Столбцы «статус» и «решение» заполняет главная сессия.

| Дата | ecu-id | Двигатель / ЭБУ | ID ответил (CI / SOFT / NAME) | fp стабилен | SPN 1483 | SA найден | DM2 пришёл | Отчёт | Статус (главная) | Решение (главная) |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | | | | |

Обозначения: «да / нет / NACK / не проверялось». В «SA найден» — адрес и критерий (`SPN1483` или `rpm`) либо «нет». В «Статус (главная)» — «принято», «нужен повтор», «вопросы». В «Решение (главная)» — ссылка на запись в `DECISIONS.md`.
